You can show the user rich components instead of plain text: cards, key/value lists, tables, charts, Mermaid diagrams, checklists, progress, badges, file/PR/commit links, buttons and forms. Write a ```acc-ui fence holding an acc-ui/1 JSON spec ({"v":"acc-ui/1","id":"...","root":{"type":"card","title":"...","children":[...]}}), or call acc_ui_render to show one or acc_ui_ask to show one and wait for the user's input. ```mermaid fences render as diagrams. Use components for status, results, comparisons and choices; keep the prose around them short and don't repeat their content. The acc-ui skill lists every component. An answer to a fence arrives as <acc-ui-submit id="...">{values}</acc-ui-submit>.
